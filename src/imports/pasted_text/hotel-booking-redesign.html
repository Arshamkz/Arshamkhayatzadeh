Hotel Booking Experience Redesign

Redesigning the hotel listing page to shift users from browsing to deciding

ROLE

Product Designer

TIMELINE

2 months

COMPANY

IranHotel

COLLABORATION

PM, PO, 2 Developers, QA

Project

IranHotel is a nationwide hotel booking platform offering reservation services for both B2C and B2B users. I worked as the sole Product Designer alongside a PM, PO, two developers, and QA over a 2-month redesign of the hotel listing page (PLP). The primary business objective was simple but critical: improve conversion and reduce drop-off at the most decisive stage of the booking funnel.

Overview and Problem

We had a main problem; low conversion rate. So we started to gather data. when we checked the main funnels, the PLP was showing something to us: Its drop-off rate was high, the hotel card CTR, engagement, and the conversion rate was low. these unlikable numbers were showing us its time to redesign. But, we had logical limits, we didn’t have the time to develop backend so much. So i had to redesign hotel booking experience with the least logical changes. at first, I had to check the Data about how the user behaves on PLP. so i checked Microsoft Clarity.

The redesign was driven by one core insight: a hotel listing page is not a collection of options—it is a decision-making environment. Every element was evaluated through the lens of: does this help users decide faster?

Research & Discovery

User behavior analysis revealed a fundamental shift in understanding—from navigation to decision-making.

Research Methods

Users scan before deciding—content hierarchy matters more than navigation

Comparison drives decisions—users need efficient side-by-side evaluation

Ambiguity reduces confidence—unclear interactions erode trust

Navigation can create funnel leakage—excess paths pull users away from booking

Higher density improves comparison when hierarchy is clear

Key Insights

💡 Initially, we believed the primary issue was related to interface organization and navigation usability

💡 After reviewing user behavior, we discovered that navigation was not helping users complete their booking journey—it was pulling them away from decision-making

💡 This shifted our focus from navigation optimization to decision optimization

Insight

Solution

The final solution transformed the PLP from a browsing interface into a decision-making environment.
It was to design a more minimal, better hierarchy, easier to compare, and a easier-to-read interface with lower cognitive load.

Trade Offs

"Information density vs. visual clarity — More details per card speeds comparison but risks overwhelming users. We prioritized scannable hierarchy to balance both."

"Persistent filters vs. screen real estate — Fixed filter bar improves access speed but reduces visible listings by ~12%. Users preferred faster filter access over one extra card per scroll."

"Removing navigation vs. discoverability — Stripping non-booking links reduces distraction but limits browsing freedom. Accepted based on session data showing navigation exits rarely returned to booking."

Outcome

Reduced fatigue.

Better comparison behavior.

Improved decision clarity.

Based on usability testing with 5 users, task completion time for comparing 3 hotels dropped from ~4 minutes to ~90 seconds.
